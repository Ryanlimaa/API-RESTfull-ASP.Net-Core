# API-RESTfull-ASP.Net-Core
Web API RESTfull usando ASP.Net Core conectado com banco de dados MySQL e Entyty Framework Core, incluindo operações CRUD e autenticação e autorização JWT para segurança.

• APIs RESTful com C# e ASP.NET Core
• Conectar a API a um banco de dados usando EF Core e MySQL
• Proteger rotas com autenticação JWT e autorização por perfil
• Aplicar boas práticas como injeção de dependência e uso de services
